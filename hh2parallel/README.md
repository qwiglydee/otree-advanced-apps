An example app with repeating tasks for 2 players

- Task: solving simple math expressions
- Input: entering number in text field
- Result: score awarded for correct answers based on how many players succeeded
- Feedback:
    - answer from parenter
    - highlighting correct/incorrect answer
    - providing correct answer
    - resulting score
- Conditions: different set of numbers in the task (odd, even, mixed)

Trial scenario:

- a task is displayed
- player-1 types answer and press 'enter'
- the response is recorded and displayed to another player
- player-2 types answer and press 'enter'
- the response is recorded and displayed to another player
- both responses get evaluated
- feedback provided
- scenario advances to next trial
    - [practice round] when players press 'continue'
    - [in main round] after some delay
