# otree-advanced-apps

Some apps for [oTtree](https://www.otree.org/) v6 with advanced features beyond standard capabilities

# Apps

- [Survey](survey/): traditional survey with some enhancements in styles and inputs
- [Quiz](quiz): simple math task with answer choice
    - tasks and choices are sampled from a data file
    - practice round: full feedback, 'continue' button
    - main round: scarse feedback, auto-continue
- [Trials 1](trials1): trials of a math task with answer by text input
    - tasks are geneated on the fly according to session condition
    - practice round: multiple retries, full feedback, 'continue' button
    - main round: single attempt, scarse feedback, auto-continue
- [Trials 2](trials2g): two-player trials with 2 stages
    - each player answers in their corresponding stage
    - practice round: full feedback, 'continue' button
    - main round: scarse feedback, auto-continue
- [Lottery 1](lottery1): lottery with cards-like buttons with different outcomes
    - outcomes of the cards are resolved according to configured distribution/condition
- [Lottery 2](lottery2s): lottery with multiple sampling choices and 1 final choice
    - outcomes of the cards are resolved for each sample and final responses
